# Work

## Description

```text
I work in an office, and most of my work involves checking information, joining meetings, and solving problems with other people.
My workplace can be busy, especially when several deadlines come at the same time.
However, I like the fact that I can learn from different projects.
When a problem is solved through teamwork, I feel a strong sense of achievement.
```

## Past Experience

```text
One day at work, I had an important meeting in the morning.
I was preparing the final file when suddenly the document would not open.
At first, I was nervous because the meeting was going to start in less than ten minutes.
So I quickly checked my backup folder and also asked a coworker to open the previous version.
Fortunately, we found a recent backup file and used it for the meeting.
After that experience, I started saving important files in two different places.
```
