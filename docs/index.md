# OPIc IH Study

목표는 AL 표현을 외우는 것이 아니라, **IM2 답변을 IH 답변 구조로 바꾸는 습관**을 만드는 것입니다.

현재 학습 흐름은 다음 순서로 설계했습니다.

1. IM2 수준 답변
2. IH 답변 구조 이해
3. IH 답변 반복 학습
4. 스크립트 없이 IH 답변 생성
5. IH 안정화

## 핵심 원칙

<div class="level-grid">
  <div class="panel">
    <strong>Connected Speech</strong>
    <p>짧은 문장을 나열하지 않고 when, because, so, fortunately로 사건을 연결합니다.</p>
  </div>
  <div class="panel">
    <strong>Story Flow</strong>
    <p>배경, 평소 상황, 사건, 반응, 행동, 결과, 느낌이 순서대로 드러나야 합니다.</p>
  </div>
  <div class="panel">
    <strong>Personal Detail</strong>
    <p>장소와 활동을 설명한 뒤, 내가 왜 그렇게 느꼈는지 개인 경험으로 마무리합니다.</p>
  </div>
</div>

## 60초 답변 기본 골격

```text
A few weeks ago...
I was...
when suddenly...
At first...
because...
So I...
Fortunately...
In the end...
What I remember most is...
```

이 사이트의 모든 주제 페이지는 같은 원리를 반복합니다. 먼저 구조를 보고, IM2와 IH 차이를 비교한 뒤, 30초와 60초 훈련으로 넘어가세요.
